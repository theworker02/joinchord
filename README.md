# joinchord

Join numeric chord values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/joinchord/

## Install / run

```bash
git clone https://github.com/theworker02/joinchord.git
cd joinchord
node src/cli.js
node --test
```
